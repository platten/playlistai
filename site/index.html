A FEW GOOD QUESTIONS

Before your
next discovery.

What do I need to get started?

Install the app for your device, then follow setup to download the recommendation catalog and your chosen models. The app handles supported model downloads and unpacking. You don’t need to install Python or prepare files yourself.

Do I need every model?

No. A local language model helps with richer descriptions, while basic interpretation is also available. Enhanced Hybrid works without optional MERT analysis. Downloading a model does not automatically enable preview analysis or experimental suggestions—you choose those in Settings.

How do I upgrade to 0.12.1?

Use the startup update prompt to read what’s new, or install the matching package from the release page. Your existing history, settings, catalog and models remain compatible. Healthy setup steps are skipped, and an optional new model won’t force you through setup again.

What if my request is a little too specific?

Strong matches come first, followed by clearly labeled close matches when suitable ones are available. Essential requirements and exclusions still apply. Missing evidence can mean a shorter playlist or a request for clarification. Try another reference or relax a preference to explore further.

Does everything work offline?

Language inference, recommendation processing, history and taste profiles run locally. Initial downloads, online music discovery, preview lookups and Soundiiz transfers need a connection. CSV export uses local track details.

Where can I read about quality and limitations?

Musical fit depends on your request and the available evidence. A preview does not establish every characteristic of a full recording. The release notes describe validation and model limitations; the recommendation guide explains how evidence is used. Installation and regression tests are not a listening-quality study.

Is Playlist AI free and open source?

Yes. The application is GPL-3.0 software. You can explore its code and build it yourself on GitHub. Optional models have their own licenses; MERT includes a noncommercial restriction. See the model distribution guide for details.
