Hear the intent.
Check the evidence.

Optional CLAP analysis compares preview audio with your description locally. Available AcousticBrainz predictions add a separate view of supported mood, genre and vocal characteristics. No Python runtime is required by the desktop app.

Supporting evidence, not a whole-song guarantee. Previews cover only part of a recording, archived classifiers can disagree, and general musical-fit calibration remains incomplete. Unverified results stay clearly marked as partial.

03 / ON YOUR TERMS

Personal taste.
Personal space.

Your descriptions, language inference, playlist history and taste profile stay on your device. No cloud model receives your prompt.

↳

At home on your desktop

Recommendations and saved feedback are processed locally. In 0.8.0, analyzed preview audio is discarded; derived features remain reusable until you clear analysis. Clear metadata cache separately without deleting playlists, taste data or the installed dataset.

↗

Clear about outside connections

Setup downloads models and data. Online discovery sends genre or reference queries to MusicBrainz or optional Discogs; AcousticBrainz receives resolved recording IDs and Deezer receives track lookups. Soundiiz receives playlist and track/artist names when you export.

A FEW GOOD QUESTIONS

Before you
press play.

Do I need a language model?

It’s optional. A local language model helps interpret richer descriptions and infer starting points. Without one, Generate works with the local catalog and asks for a seed artist or track.

Does everything work offline?

Language inference, recommendation processing, history and taste profiles stay local. Setup needs downloads, and metadata discovery, preview lookups and Soundiiz handoff use external services. CSV export uses local track details.

Can I use my own CLAP model?

Yes, with compatible paired encoders, tokenizer, preprocessing and reference checks. Different checkpoints keep separate embedding caches. Read the custom-bundle guide for the contract and links to training and export documentation.

Does CLAP work on every build?

Native inference was validated on Linux x64 under WSL2. The standard pure-Go Windows build needs a native-enabled build or a legacy bundle with its own worker. Hardened macOS builds still need a signing strategy for downloaded runtimes. See the documented limitations before installing analysis models.

How do I upgrade to 0.8.0?

Once it is published, install the matching package from GitHub Releases. Existing 0.7.0 binaries do not have the new updater. Version 0.8.0 introduces verified update downloads for supported installations; packaged cross-platform upgrade checks are still pending.

Why might I get fewer tracks than requested?

Not every description or recording has enough supporting evidence. Playlist AI explains partial results rather than filling the list with tracks that fail essential requirements. You can refine your description or choose another reference.

Can I build it myself?

Absolutely. Playlist AI is GPL-3.0 software built with Go, Wails and React. The repository setup instructions cover the desktop toolchain. Python is not a desktop runtime requirement.
