A FEW GOOD QUESTIONS

Before your
next discovery.

What do I need to get started?

Install the app for your device, then complete every step in the setup wizard. All components are required. Playlist AI checks for existing assets before downloading the catalog, local language model, CLAP analysis and MERT pack it needs. You don’t need to install Python or prepare files yourself.

Why is every component required?

Every component has a role in getting your music ready. CLAP connects your words with analyzed audio, MERT adds audio-to-audio similarity from a reference, and the local language model interprets natural requests. Installed compatible assets are reused automatically.

How do I upgrade to 0.15.0?

Install the matching package from the release page. On Windows, close every Playlist AI window first, then run the installer in your existing installation folder. If an older copy is still running, restart Windows before installing. Your existing history, settings, catalog and model files remain compatible. Setup checks what is already installed and shows only required work that is still missing.

What if my request is a little too specific?

The strongest grounded matches are selected first. Essential requirements and exclusions still apply. Missing evidence can mean a shorter playlist, an actionable limitation or a request for clarification. Try another reference or relax a preference to explore further.

Does everything work offline?

Prompt interpretation, recommendation processing, history and taste profiles run locally. Initial downloads, online music discovery, preview lookups and Soundiiz transfers need a connection. CSV export uses local track details.

Where can I read about quality and limitations?

Musical fit depends on your request and the available evidence. A preview does not establish every characteristic of a full recording. The release notes describe validation and model limitations; the recommendation guide explains how evidence is used. Installation and regression tests are not a listening-quality study.

Is Playlist AI free and open source?

Yes. The application is GPL-3.0 software. You can explore its code and build it yourself on GitHub. Required models have their own licenses; MERT includes a noncommercial restriction. See the model distribution guide for details.
