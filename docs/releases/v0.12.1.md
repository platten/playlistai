# Playlist AI v0.12.1 — Hosted models, simpler setup

Playlist AI 0.12.1 makes the model packs introduced alongside 0.12.0 directly
installable from **Settings and the setup wizard**. It also makes **Enhanced
Hybrid the default recommendation mode** for new installations and unset
preferences. These notes cover changes since v0.12.0.

## 📥 Download models directly in the app

You no longer need to download, join, or extract model archives manually.

- **Intent language models:** Settings downloads the hosted DistilBERT and
  MiniLM encoder pack. The wizard starts this download when those assets are
  missing. Verified encoders are reused when only the native runtime needs repair.
- **MERT:** choose **Download MERT for this device**. The app selects Windows
  x86-64 or ARM64, Linux x86-64 or ARM64, or macOS Apple Silicon automatically.
  Unsupported targets display an explanation before any download starts.
- **Resumable segments:** each pack contains two compressed parts, with a maximum
  of 190 MB per part. Completed verified segments survive cancellation and are
  reused on retry.
- **Native assembly and extraction:** the app joins the segments as a stream,
  decompresses them, and verifies every extracted file. No Python installation
  is required to download or run the models.
- **Existing imports remain available:** advanced users can still provide a
  custom HTTPS manifest, a local manifest, or an unpacked MERT directory.

### Download sizes

| Pack | Compressed total | Segments |
| --- | ---: | ---: |
| DistilBERT + MiniLM | 324.06 MB | 2 |
| MERT · Windows x86-64 | 213.88 MB | 2 |
| MERT · Windows ARM64 | 214.01 MB | 2 |
| MERT · Linux x86-64 | 216.26 MB | 2 |
| MERT · Linux ARM64 | 215.50 MB | 2 |
| MERT · macOS Apple Silicon | 217.33 MB | 2 |

Sizes use decimal MB. Compression is **lossless**: no quantization, pruning or
precision reduction was applied. Intent encoders are shared across platforms;
their matching native runtime is downloaded separately if missing. MERT packs
include their platform runtime and, on Windows, the required app-local DLLs.

## 🧭 Enhanced Hybrid by default

New installations and unset or invalid mode preferences now use Enhanced
Hybrid. The playlist screen's fallback agrees with that default.

Explicit saved mode choices remain respected, as does an explicit legacy
Deej-AI configuration. The default-mode change does not automatically download
models, enable preview analysis, or turn on experimental intent suggestions.
MERT remains optional; missing evidence is still treated as unknown.

## ✨ A wizard that knows what is already installed

Setup offers an optional MERT step after music analysis. It selects the same
platform pack as Settings, shows download progress, and supports cancellation
and retry. The **Enable bounded preview analysis** checkbox lets you explicitly
choose whether to use enhanced audio evidence.

Healthy installed assets are skipped. A completed installation is not sent
through setup just because MERT is newly available; previously selected models
with missing files can still trigger focused repair steps. Downloading a model
does not silently change your analysis preferences.

## 🔒 Verified downloads and confined extraction

Built-in R2 manifest URLs and SHA-256 hashes are pinned in the application.
Every compressed segment and extracted file also has an expected size and hash.
Unexpected manifest changes are rejected before downloading segments.

The transport enforces size limits, refuses HTTPS downgrades, and rejects
absolute paths, traversal, links, duplicates and unlisted archive entries.
Extraction now also uses Go's filesystem-root API to confine filesystem access
to the staging directory. Model-specific compatibility and native health checks
remain in place before activation.

## 📊 Validation and model limitations

All six real hosted packs were downloaded through the native Go transport,
reassembled, decompressed and checked against their original file hashes.
R2 byte-range support was verified for resumable downloads. The downloaded
Windows MERT pack passed native parity, cancellation and restart checks.
MiniLM passed 17 embedding/tokenizer reference cases, and DistilBERT passed
17 tokenizer cases. The feature validation included 199 frontend tests, the Go
race suite, lint and browser checks in both themes and narrow/wide windows.

These are installation and regression checks, not a new listening study.
MiniLM suggestions remain experimental. The trained DistilBERT pilot remains
**inactive** because its expanded calibration did not establish useful additional
intent extraction. Shipping the base encoder does not change that conclusion.

MERT retains its **CC-BY-NC-4.0 noncommercial license**. DistilBERT and MiniLM
retain their Apache-2.0 licenses; native runtimes include their own notices.

## 📦 Installing or upgrading

| Platform | Architectures | Packages |
| --- | --- | --- |
| Windows | x86-64, ARM64 | NSIS installer or portable ZIP |
| Linux | x86-64, ARM64 | AppImage, DEB, RPM, Arch package or portable tar.gz |
| macOS | Apple Silicon | DMG or portable application ZIP |

Upgrade the application to **v0.12.1** to get the hosted model controls;
v0.12.0 cannot directly consume the segmented manifests. Existing settings,
history, catalogs and installed models are retained. Model weights remain
separate downloads rather than being added to every application installer.
Allow temporary disk space for compressed segments, extracted files and the
installed copy. Windows ARM64 is cross-compiled; build success is not native
execution evidence. Installed-updater flows have not been tested on every OS.
